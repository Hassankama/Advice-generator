# Advice Generator

A responsive Advice Generator application that fetches random advice from the Advice Slip API.

## Features

- Generate random advice with a single click.
- Fetch real-time advice from an external API.
- Responsive design for desktop and mobile devices.
- Interactive dice button.

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Fetch API
- Async JavaScript

## API Used

[Advice Slip API](https://api.adviceslip.com/)

The application sends a GET request to retrieve a random advice slip and dynamically updates the advice ID and text.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
